# Task Manager: user stories

No logins yet: everyone who opens the app shares the same projects and tasks. Accounts come in a future lecture.

1. As a user, I want to create projects with a name and a description so that I can organize my work.
2. As a user, I want to create tasks with a title so that I can track what I need to do.
3. As a user, I want to assign a task to a project (or leave it on its own) so that I can keep related work together.
4. As a user, I want to give a task a due date so that I know what's coming up.
5. As a user, I want to mark tasks as complete so that I know what I've finished.
6. As a user, I want to label tasks with tags like "school" or "urgent" (a task can have several) so that I can filter my list.
7. As a user, I want to see when each task was created so that I can spot old ones.
