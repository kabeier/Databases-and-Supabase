Noun Hunt: Recipe Box

Read the user stories. Which nouns become tables? Which details become columns? Click a word once to mark it as a table, twice for a column, a third time to clear it.

tablecolumn
  1. As a home cook, I want to create an account with a username and email so that my recipes are saved to me.
  2. As a home cook, I want to post a recipe with a title, instructions, a cooking time, and a photo so that I can share it.
  3. As a home cook, I want to put each recipe in one category, like Breakfast or Dessert, so that people can browse.
  4. As a home cook, I want to list the ingredients for a recipe with an amount for each (2 cups flour) so that others can shop for it.
  5. As a home cook, I want to leave a star rating from 1 to 5 and a comment on a recipe so that I can say how it went.
  6. As a home cook, I want to mark a recipe as vegetarian so that people can filter for it.
  7. As a home cook, I want to save other people's recipes to my favorites so that I can find them later.
Post in chat like this: 
recipes: title, instructions, ...
users: ...
(one line per table)

Answer key

users

  • id UUID (PK)
  • username VARCHAR(50)
  • email VARCHAR(255)
  • created_at TIMESTAMPTZ

"home cook" and "account" both mean a user.

recipes

  • id UUID (PK)
  • title VARCHAR(255)
  • instructions TEXT
  • cook_minutes INTEGER
  • photo_url TEXT
  • is_vegetarian BOOLEAN
  • author_id → users
  • category_id → categories
  • created_at TIMESTAMPTZ

categories

  • id UUID (PK)
  • name VARCHAR(50)

A fixed list people browse. (A plain text column also works for a tiny app.)

ingredients

  • id UUID (PK)
  • name VARCHAR(100)

reviews

  • id UUID (PK)
  • rating INTEGER (1–5)
  • comment TEXT
  • user_id → users
  • recipe_id → recipes
  • created_at TIMESTAMPTZ

recipe_ingredients

  • recipe_id → recipes
  • ingredient_id → ingredients
  • amount VARCHAR(50)

Hidden table #1. "2 cups" belongs to this recipe plus this ingredient, so it lives on a junction table.

favorites

  • user_id → users
  • recipe_id → recipes
  • saved_at TIMESTAMPTZ

Hidden table #2. A user saves many recipes; a recipe is saved by many users.

Traps
  • photo is a column (a URL to the image), not a table.
  • vegetarian is a yes/no column: is_vegetarian BOOLEAN.
  • star rating is a column on reviews, not its own table.
  • cooking time: store a number of minutes (INTEGER), not text like "about an hour".
  • Nobody asked for created_at, but nearly every table gets one.
