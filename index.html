Homework setup: your database, step by step

1 · Draw your database

  1. Open drawsql.app/draw, choose PostgreSQL, then Start with a blank canvas.
  2. Add a table per noun in your user stories, a column per detail, and a type for every column. Drag from a foreign key column's dot onto the column it points at to draw a relationship.
  3. Take a screenshot of the whole diagram (Mac: Cmd+Shift+4, Windows: Win+Shift+S, Linux: Print Screen). Exporting is a paid DrawSQL feature; a screenshot is all Claude needs.
  4. Without an account, the diagram is saved only in that browser. A free account keeps it (public diagrams, up to 15 tables).

2 · Create a Supabase project and a folder for it

  1. At supabase.com, sign in with GitHub. The first time, Supabase asks you to create an organization: your name, type Personal, Free plan.
  2. New project, and fill in the form top to bottom:
    • Organization: yours. GitHub (optional): leave empty. Project name: your app's name.
    • Database password: click Generate a password, then Copy, and save it in a password manager before you continue. Supabase never shows it again (you can reset it later in Project Settings → Database). Never put it in your repo.
    • Region: the one closest to you.
    • Security: keep Enable Data API ✓ and Automatically expose new tables ✓, and turn Enable automatic RLS ✓ on.
    • Leave Advanced configuration alone → Create new project.
  3. Make a supabase folder next to your app's front-end folder, like ticked/front-end and ticked/supabase in class. Put your diagram screenshot and a user_stories.md in it. 
    cd ~/path/to/my-app     # your project's root folder
mkdir supabase
cd supabase
    Your app's code goes in a front-end folder beside it. If it's sitting loose in the root folder right now, that's fine for today; we'll organize it when we connect the two halves.

3 · Connect Claude Code with the Supabase MCP

  1. In your Supabase project, click Connect in the top bar → MCP → Claude Code, and copy the command. It looks like this (yours has your own project_ref): 
    claude mcp add --scope project --transport http supabase "https://mcp.supabase.com/mcp?project_ref=YOUR_REF"
  2. Paste it in a terminal inside your folder (not inside Claude). Windows: use the Ubuntu (WSL) app.
  3. Start claude, trust the folder, and choose Use this MCP server.
  4. Type /mcp → supabase → Authenticate. Approve in the browser tab that opens, then come back.

4 · Add the database design skill (and Context7)

  1. In a terminal in the same folder: 
    curl -fsSL https://kabeier.github.io/Databases-and-Supabase/demo-kit/setup-db-skill.sh | bash
    It should finish with a ✓ line. Inside Claude, /skills should list postgresql-table-design.
  2. If you don't have Context7 from the SPA lecture yet (claude mcp list to check): 
    claude mcp add --scope user context7 -- npx -y @upstash/context7-mcp
The skill script failed? Install it by hand (no git needed)

Run this in your folder. It downloads the skill's two files into the right place:

S=.claude/skills/postgresql-table-design
R=https://raw.githubusercontent.com/wshobson/agents/main/plugins/database-design/skills/postgresql-table-design
mkdir -p $S/references
curl -fsSL $R/SKILL.md -o $S/SKILL.md
curl -fsSL $R/references/details.md -o $S/references/details.md

5 · Paste the prompt, then verify every table

  1. Start from the class prompt. Change the first sentence to describe your app and the file names to yours.
  2. Review schema.sql before you approve it. Row Level Security should be on for every table. After each table, check the Table Editor. When it's done, the Schema Visualizer should match your diagram.
  3. Add the Supabase sub-agent to the same folder (we use it when we connect the front-end in a future lecture): 
    mkdir -p .claude/agents && curl -fsSL https://raw.githubusercontent.com/kabeier/Databases-and-Supabase/main/demo-kit/.claude/agents/supabase-agent.md -o .claude/agents/supabase-agent.md
